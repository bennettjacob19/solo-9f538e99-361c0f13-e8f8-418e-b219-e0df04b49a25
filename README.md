# svc.test. 区域发布系统

面向运维的内网 `svc.test.` 区域发布平台：FastAPI 操作网页 + dnslib UDP 权威 DNS + SQLite 版本存储。
网页整版提交 A/CNAME 记录、查看当前版本、发起真实 UDP 查询；发布原子生效，查询永不被发布打断。

## 快速开始

```bash
docker compose up --build
# 网页:  http://localhost:8000
# DNS:   dig @127.0.0.1 -p 5353 app.svc.test. A
```

单容器同时运行网页（8000/tcp）与权威 DNS（5353/udp），SQLite 落在命名卷 `zone-data` 里，重启不丢版本。

本地直跑（Python 3.11+）：

```bash
python -m venv .venv && .venv/bin/pip install -r requirements.txt
ZONE_DB=data/zone.db DNS_BIND=127.0.0.1 DNS_PORT=5353 WEB_PORT=8000 .venv/bin/python -m app.main
```

## 区域文本格式

每行一条记录，`#` 起为注释，名称可写相对名或 FQDN：

```
web A 10.0.0.10 60
web A 10.0.0.11 60        # 同名多 A 轮询
api CNAME web             # 别名只能指向本区域已定义的名称
app CNAME api             # 允许多级链，必须终结于 A 记录
```

每次提交即一个**完整新版本**（不是增量）。规则：

- CNAME 目标必须是本版本内已定义的 `svc.test.` 区域内名称；悬空、循环（含自环）、指向区域外，整版拒绝；
- 同一名称不能同时有 A 与 CNAME；A 值必须是合法 IPv4；
- 校验或写入任一失败，整版不生效，当前版本继续服务。

## IPv4 退役（旧后端摘除）

停用旧后端前，在首页「IPv4 退役」表单从**现行区域**里选择一个 IPv4 发起退役：

- **受理前提**：该地址当前必须出现在区域中，且指向它的每个名称都保留至少一个
  未退役的备用 A（候选地址自身也算退役，因此名称只有这一个 A 时会被拒绝）。
- **截止时间**：受理时刻 + 该地址**历次已发布 A 记录中的最大 TTL**（即使后来把
  TTL 调低，旧版本里的高 TTL 仍然计入）。截止时间在网页与 `/api/retirements` 展示。
- **到期前**：查询指向该地址的名称仍会得到它；应答里整组 A 记录的 TTL 统一截到
  「距截止的剩余整秒」（经 CNAME 链查到的 A 同样处理，CNAME 自身 TTL 不动）；
  多个地址同时退役时取最小剩余秒数。
- **到期后**：新查询自动摘除该地址，同名称的备用 A 继续应答，无需再发版。
- **发布约束**：到期前整版提交必须保持该地址对应的名称集合，且每个名称至少保留
  一个未退役备用 A；到期后整版提交中再出现该地址，整版拒绝发布。
- **顺序与幂等**：退役与发布共用同一把串行锁，严格按提交顺序生效；每次 DNS 查询
  捕获同一个已提交的「区域 + 退役状态」不可变视图。写入失败维持原状态；重复发起
  （含重启后）同一地址直接沿用原截止时间，不会产生第二条记录。
- 截止时间是绝对时间戳，落在 SQLite 中，重启后继续倒数；到期状态无需后台任务，
  在每次查询时按当前时间即时判定。


## 一致性与原子性设计

- **整版原子发布**：版本行 + 全部记录行 + `current_version` 指针在同一个 SQLite 事务
  （`BEGIN IMMEDIATE … COMMIT`）中落库；任何写入失败整体回滚，库中不会留下半版，
  重启后按指针恢复的只会是完整版本。
- **发布期间照常解析**：DNS 线程只读内存中的不可变 `View`（`Snapshot` + 退役状态）；
  发布或退役提交成功后一次性原子换引用，查询不等待、不阻塞。
- **单次查询同一状态**：每个查询在开始时捕获一次视图引用，整条 CNAME 链、最终 A
  地址与退役摘除/TTL 截短都来自这同一个已提交状态，绝不跨提交拼接。
- **重启恢复**：启动时从 SQLite 读取 `current_version` 与全部退役行重建视图；退役
  截止时间是绝对时间戳，重启后继续倒数。另有每 2 秒（`REFRESH_INTERVAL`）的对账
  线程兜底，DB 与内存不一致时以库为准。

## 网页与 API

| 入口 | 说明 |
| --- | --- |
| `GET /` | 当前版本记录、IPv4 退役表单与截止时间、发布表单（预填当前版）、查询表单、版本历史 |
| `POST /publish` | 表单 `zone_text` + `note`；校验失败 400、写入失败 500、成功 303 |
| `POST /retire` | 表单 `ip`：从现行区域发起 IPv4 退役；不合规 400、写入失败 500、成功/重复 303 |
| `GET /query?name=&qtype=` | 网页发起真实 UDP 查询（A/CNAME/ANY） |
| `GET /api/current` | 当前版本 JSON |
| `GET /api/versions` | 版本历史 JSON |
| `GET /api/retirements` | 退役状态 JSON（截止时间、最大历史 TTL、剩余秒数、是否生效中） |

## 环境变量

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `ZONE_DB` | `./data/zone.db`（镜像内 `/data/zone.db`） | SQLite 路径 |
| `DNS_BIND` / `DNS_PORT` | `0.0.0.0` / `5353` | UDP 权威 DNS 监听 |
| `WEB_HOST` / `WEB_PORT` | `0.0.0.0` / `8000` | 网页监听 |
| `DNS_QUERY_HOST` | `127.0.0.1` | 网页发起查询的目标地址 |
| `REFRESH_INTERVAL` | `2.0` | 内存快照与 DB 对账周期（秒） |

## 验证

```bash
.venv/bin/python tests/e2e_test.py        # 区域发布：原子性、校验、并发一致性、重启恢复
.venv/bin/python tests/retire_e2e_test.py # IPv4 退役：截止时间、TTL 截短、摘除、发布约束、幂等、重启
```

`e2e_test.py` 覆盖：事务原子性（唯一约束触发半途失败 → 无半版）、整版校验拒绝
（悬空/循环/外部目标/类型冲突/非法地址/区域外名称）、链式解析与
NXDOMAIN/REFUSED/NODATA、发布期间并发查询的单版本一致性、写入失败（DB 路径被
替换为目录 → 500、旧版照常应答、恢复后可继续发布）、重启后版本与记录完整恢复。

`retire_e2e_test.py` 覆盖：历史最大 TTL（调低 TTL 仍计入旧版高值）、退役受理
校验（地址须在现行区域、每个指向名称须有未退役备用 A）、截止时间 = 受理 + 最大
TTL、到期前整组 A（含 CNAME 链末端）TTL 截到剩余整秒而 CNAME TTL 不变、到期自动
摘除、到期前名称集合/备用 A 发布约束、到期后禁止该地址再发布、写入失败维持原状、
重复发起与重启后沿用原截止时间、发布与退役交错提交下的查询一致性。
